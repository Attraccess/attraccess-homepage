How It Works

Get up and running in minutes

From zero to full machine access control — no custom firmware, no electrical engineering degree required.

Step 1

Define Your Resources

Add each machine as a "resource" in the dashboard. Give it a name, description, and upload a photo. Set safety requirements — like requiring training before access is granted.

  • Name, photo, description
  • Training & certification requirements
  • Location & group assignment

Step 3

Deploy & Let Members Use It

Install an NFC reader (Raspberry Pi, ESP32, or any HTTP-capable device) next to each machine. Members tap their card — access is verified in milliseconds and the relay activates.

  • Works with Raspberry Pi, ESP32, PN532
  • Sub-200ms tap-to-unlock response
  • GPIO, HTTP webhook, MQTT relay output

Step 4

Track Usage & Automate Workflows

Every access event is logged. View usage by machine, user, time of day, or location. Set up automations to notify Slack, trigger billing, or lock machines after hours.

  • Full audit log, forever
  • Automation triggers & webhooks
  • Exportable CSV reports
